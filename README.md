# EcoLife 

Création d'un site web proposant des défis écologiques pour aider les jeunes à réduire leur impact sur l'environnement. Le site vise les **20 à 30 ans** qui veulent adopter des gestes plus responsables au quotidien, avec la possibilité de **créer un compte** pour personnaliser les défis et suivre sa progression.
